# Cloudflare Worker Starter for Manyfold Agents

This file is retained for compatibility with existing links. The repository documentation is
maintained in British English; see the main [README](README.md).

The application is a Cloudflare Workers template pre-wired with [Manyfold](https://manyfold.ai)
AI-agent connectivity. It includes the device-code connection flow, streaming agent chat, D1
persistence, encrypted credentials, and a React application ready to extend.

For deployment, local development, architecture, extension guidance, and security notes, follow
the instructions in the [main README](README.md).
